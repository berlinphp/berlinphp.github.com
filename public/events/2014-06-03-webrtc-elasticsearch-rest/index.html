Meetup on the 3rd of June, 2014

📅 June 03, 2014
📍 co.up Coworking Space, Adalbertstr. 7-8, 10999 Berlin

June 2014 meetup featuring WebRTC real-time communication by Daniel Fahlke, Elasticsearch integration by Christoph Lühr, and REST API principles by Till Klampäckel.

Talk 1: WebRTC

Real-time peer-to-peer communication in the browser.

by Daniel Fahlke aka Flyingmana

Talk 2: Elasticsearch for PHP developers

How to integrate powerful search capabilities into your PHP applications.

by Christoph Lühr

Talk 3: REST - more than GET and POST

Understanding the full spectrum of HTTP methods and REST principles.

by Till Klampäckel

👥 Speakers

Daniel Fahlke
Christoph Lühr
Till Klampäckel
