Meetup on the 1st of November, 2016

📅 November 01, 2016
📍 co.up Coworking Space, Adalbertstr. 7-8, 10999 Berlin

November 2016 meetup featuring SOAP webservices, Siesta ORM - [Slides](siesta.pdf) for PHP7, and GitHub Archive analysis.

Talk 1: SOAP is beautiful (again)

Enjoy using legacy SOAP webservices with a brand new SOAP client

by Asmir Mustafic

Talk 2: Siesta ORM - Slides for php7

Stored procedure based object relational mapper for php7

by Gregor Müller

Talk 3: Parse the GithubArchive for Fun - Slides (improvised)

What Data it has, where it comes from, and how to play with it.

by Daniel Fahlke aka Flyingmana
