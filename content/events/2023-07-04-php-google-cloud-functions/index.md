## Talk 1: PHP and Google Cloud Functions

I'll use a [simple open-source tool](https://github.com/snoofa-com/statuspage-and-gcp-monitoring) that connects Google's Uptime Checks to Atlassian Statuspage as an example showing you how PHP can be used in Google Cloud Functions and how it can interact with Pub/Sub. We'll walk through the process of building and deploying a PHP 8.1 function. (lightning talk)
